# My Portfolio 🌐

A responsive personal portfolio website built to showcase my skills, projects, experience, and contact information as a Front-End Web Developer.

## 🚀 Live Demo

🔗 [View Live Portfolio]((https://my-portfolio-sepia-theta-65.vercel.app/))

## 📌 About The Project

This portfolio was developed as part of **Task 1 – Responsive Personal Portfolio Landing Page** for the **Live Pakistan Front-End Web Development Internship Program**.

The goal of the project was to create a professional, responsive, and interactive personal portfolio using HTML, CSS, and JavaScript.

## ✨ Features

- Fully responsive design
- Mobile, tablet, and desktop support
- Hero / Introduction section
- About Me section
- Skills section
- Work Experience section
- Projects showcase
- Contact section
- Responsive navigation
- JavaScript animations and interactions
- Front-end contact form validation
- Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Font Awesome
- Google Fonts

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- 📱 Mobile
- 📲 Tablet
- 💻 Laptop
- 🖥️ Desktop
